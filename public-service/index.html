Public services

I run a few open source projects, feel free to use them. They are provided on a best-effort basis and may change or become unavailable without notice.

Running

  • BrainMax - a TikTok-style feed for browsing research papers (arXiv, medRxiv, bioRxiv, PubMed, Hacker News) with simplified abstracts and daily visual explainers. Started as a fork of ArxivTok.
  • LLM Token Calculator - count tokens and estimate cost for a given text across LLM models.

Open data

  • Hacker News dataset - every Hacker News item since 2007 as monthly Parquet files, updated daily. Files live at https://hacker-news.adhikasp.my.id/year=YYYY/month=M/data.parquet, so you can query them directly with DuckDB.

Open source tools

  • hn-data-fetcher - a fast async tool that fetches Hacker News items into a local SQLite database. I used it for the AI shift on Hacker News.
  • MCP Client CLI - a command line client for talking to LLMs through Model Context Protocol servers.
  • Kodepos - visualizes Indonesia’s postal code regions hierarchically.
  • MCP servers: mcp-twikit (Twitter/X), mcp-git-ingest (read a GitHub repo), mcp-reddit and mcp-youtube.
