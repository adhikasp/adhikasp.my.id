I run a few open source projects, feel free to use them. They are provided on a best-effort basis and may change or become unavailable without notice.

## Running

- <a href="https://brainmax.adhikasp.my.id/">BrainMax</a> - a TikTok-style feed for browsing research papers (arXiv, medRxiv, bioRxiv, PubMed, Hacker News) with simplified abstracts and daily visual explainers. Started as a fork of <a href="https://github.com/Miguel07Alm/arxivtok">ArxivTok</a>.
- <a href="https://adhikasp.github.io/llm-token-calculator/">LLM Token Calculator</a> - count tokens and estimate cost for a given text across LLM models.

## Open data

- <a href="https://hacker-news.adhikasp.my.id/year=2026/month=10/data.parquet">Hacker News dataset</a> - every Hacker News item since 2007 as monthly Parquet files, updated daily. Files live at `https://hacker-news.adhikasp.my.id/year=YYYY/month=M/data.parquet`, so you can query them directly with DuckDB.

## Open source tools

- <a href="https://github.com/adhikasp/hn-data-fetcher">hn-data-fetcher</a> - a fast async tool that fetches Hacker News items into a local SQLite database. I used it for [the AI shift on Hacker News](/posts/ai-shift-on-hacker-news/).
- <a href="https://github.com/adhikasp/mcp-client-cli">MCP Client CLI</a> - a command line client for talking to LLMs through Model Context Protocol servers.
- <a href="https://github.com/adhikasp/kodepos">Kodepos</a> - visualizes Indonesia's postal code regions hierarchically.
- MCP servers: <a href="https://github.com/adhikasp/mcp-twikit">mcp-twikit</a> (Twitter/X), <a href="https://github.com/adhikasp/mcp-git-ingest">mcp-git-ingest</a> (read a GitHub repo), <a href="https://github.com/adhikasp/mcp-reddit">mcp-reddit</a> and <a href="https://github.com/adhikasp/mcp-youtube">mcp-youtube</a>.
